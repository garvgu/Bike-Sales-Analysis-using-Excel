# 🏍️ Bike Sales Analysis Dashboard

## 📌 Project Overview

The Bike Sales Analysis project explores bike-related data to understand pricing trends, resale values, fuel types, brand distribution, ownership patterns, and regional differences. The project uses Microsoft Excel, pivot tables, and dashboard-based reporting to summarize the dataset and support data-driven insights.

## 🎯 Project Objectives

- Analyze average bike prices across different brands.
- Compare original prices with resale prices.
- Understand the distribution of bikes by fuel type.
- Explore bike data across states and city tiers.
- Analyze manufacturing years, engine capacity, and mileage.
- Examine insurance status, owner type, and seller type.
- Present key findings through pivot tables and a dashboard.

## 📂 Dataset Description

The workbook contains **10,000 records and 15 columns**.

| Column | Description |
|---|---|
| State | State associated with the bike record |
| Avg Daily Distance (km) | Average daily distance covered |
| Brand | Bike manufacturer |
| Model | Bike model |
| Price (INR) | Listed bike price |
| Year of Manufacture | Year the bike was manufactured |
| Engine Capacity (cc) | Engine displacement |
| Fuel Type | Electric, Hybrid, or Petrol |
| Mileage (km/l) | Mileage value recorded |
| Owner Type | Ownership category |
| Registration Year | Year of registration |
| Insurance Status | Recorded insurance status |
| Seller Type | Individual or Dealer |
| Resale Price (INR) | Recorded resale price |
| City Tier | Geographic city category |

## 🛠️ Tools and Techniques

- **Microsoft Excel** — Data exploration and analysis
- **Pivot Tables** — Summarizing and comparing categories
- **Excel Dashboard** — Visual presentation of analysis
- **Data Cleaning** — Checking missing values and duplicate records

## 📊 Key Findings

Based on the workbook's dataset:

- **10,000 records** are available for analysis.
- **8 bike brands** are represented.
- The average listed price is approximately **₹2.24 lakh**.
- The average recorded resale price is approximately **₹1.34 lakh**.
- Hybrid fuel has the highest record count, with 3,360 records, followed by Petrol with 3,357 and Electric with 3,283.
- Bajaj has the highest average listed price among the eight brands, at approximately ₹2.31 lakh.
- The dataset includes 10 states and multiple city tiers.
- No missing values or exact duplicate rows were detected in the 15 dataset columns during the initial check.

*These findings describe the supplied dataset and should not be interpreted as market-wide statistics.*

## 📈 Project Components

The Excel workbook contains three sheets:

1. **Bike Sales Analysis.xlsx** — Raw dataset.
2. **Pivot_Table** — Summary tables for brand prices, resale prices, fuel types, models, states, manufacturing years, and city tiers.
3. **Dashboard** — Dashboard sheet included in the workbook.
